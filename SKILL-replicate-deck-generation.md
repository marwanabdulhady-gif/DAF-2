# Skill — Build the Wadi al-Amanah Projector Decks & Gamified Activity Engines

**Product:** The offline companion teaching system for **Dar Al Fikr Boys School, Jeddah**.  
It turns the 91 printed math lessons (Grade-4 enVision Mathematics, 16 topics) into:

1. **Projector decks** — One self-contained `.html` per door (`slides/door-X-Y.html`), playable on classroom projectors with rich interactive 2D activity engines and game mechanics.
2. **Learning Hub application** — `hub/index.html` with unified glass-chrome styling, live interactive SVG valley map, mini-game arcades, student portfolios, and caravan tracking.
3. **Practice slips & Portfolios** — Printable A5/A4 Sijill sheets (`hub/#/portfolios` & `slides/PRODUCTION.html`).
4. **Companion pages** — `EXPERIENCES.html`, `PRODUCTION.html`, `period-hive.html`, and `wadi-map.html`.

### 🎯 Strict Visual Contrast & Legibility Rules
- **No Dark-on-Dark Text:** Every subheading, prompt, clue, and mathematical equation must be rendered in **high-contrast bright colors**:
  * Primary text: Crisp white `#ffffff` or pearl `#f2f9fa`.
  * Formulas & Numbers: Glowing Cyan `#38effa` or Radiant Gold `#f6d872`.
  * Sub-instructions: Soft turquoise `#a4e2ea` or champagne gold `#e6d5a8` with at least 8:1 contrast ratio against the background.
- **Frosted Glass Cards:** Game containers and dialogue boxes use `backdrop-filter: blur(16px)`, `background: rgba(6, 24, 32, 0.88)`, and glowing borders (`1.5px solid rgba(0, 190, 214, 0.4)`).
- **Embossed Chips & Buttons:** Scramble word chips and game buttons use embossed glass pills with glowing cyan/gold borders and bold typography.

## 3. Universal 2D Activity Engine Verbs

The built-in `ActivityEngine` provides 22 offline, zero-dependency interactive verbs:

| Engine Verb | Best Pedagogical Use | Interaction Mechanic |
|---|---|---|
| `treerings` | Inverse comparison division (e.g. Door 6-2) | Drag divider to segment total into equal parts |
| `airplane` | Mental arithmetic & rapid calculation speed | Fly aircraft through quotient clouds (arrow/touch) |
| `matching` | Connecting representations / equations | Tap pairs on left and right to draw glowing lines |
| `cloze` | Mathematical vocabulary & principle statements | Drag missing words into sentence slots |
| `compare2` | "Convince Me!" discourse & error analysis | Side-by-side student argument analysis |
| `pick` | Multiple-choice algebraic modeling | Select valid equation row with instant feedback |
| `scratch` | Stage 0 mystery problem reveal | Scratch canvas foil with pointer to reveal image |
| `wheel` | Random challenge / student selector | Canvas physics spinner with friction deceleration |
| `openthebox` | Multi-step problem solving | Tap numbered vaults to reveal sub-questions |
| `cardsort` | Concept classification (Prime/Composite, Shapes) | Drag item cards into target category bins |
| `wodb` | "Which One Doesn't Belong?" | Pick card and justify distinct mathematical property |

## 4. Quality Assurance & Invariant Checklist

Before finalizing any deck (`door-X-Y.html`):

1. [x] **Zero CDN Dependencies:** All styles, scripts, SVGs, and fonts run completely offline (`file://` and local `http://` compatible).
2. [x] **High Contrast Verified:** All subheadings, prompt text, and equations are legible against dark glass cards.
3. [x] **Vector Avatars:** Clean SVG avatars with lively natural eyes, expressive pupils, and gold halos.
4. [x] **Web Audio Synthesis:** Sound effects generated via `AudioContext` oscillators (zero `.mp3` dependencies).
5. [x] **Projector Stage Scaling:** Responsive 1920×1080 canvas scales smoothly to any classroom display.
6. [x] **Locked Textbook Figures:** Numbers match printed enVision 2024 textbook figures strictly.
7. [x] **Concrete Twin Runs First:** Physical manipulative twin specified and referenced prior to screen work.
8. [x] **Clean Code:** No injected third-party tracking or challenge scripts.
9. [x] **Direct Hub Return:** Header links seamlessly to `../hub/index.html`.
